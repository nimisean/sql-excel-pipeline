# SQL-to-Excel Data Pipeline Magic ✨

Today I built an automated pipeline that transforms raw SQL data into powerful Excel dashboards!

## 🔧 Tech Stack:
- **Backend**: PHP + MySQL
- **Frontend**: JavaScript + Chart.js
- **Data Tools**: Oracle SQL + MS Excel Power Query

## 🎯 What it does:
- Extracts complex data from Oracle database
- Processes with PHP data transformation logic
- Exports to Excel with dynamic charts & pivot tables
- Automated refresh capabilities

## 💡 Cool Feature:
Created a "one-click" report generator that business users can run without touching code!
